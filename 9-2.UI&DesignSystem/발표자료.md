## 2. JSON Schema와 커넥터 UI

**UI 페이지**

`Settings > Services > Add New Service`

1. JSON Schema에서 연결 정보와 `source_type`을 정의한다.
2. `quicktype`이 UI용 TypeScript 타입을 생성한다.
3. 서비스 설정 UI는 생성 타입과 연결 규칙을 사용한다.

```bash
# openmetadata-ui/.../json2ts.sh
quicktype -s schema "$tmp_schema_file" \
  -o "$output_file" --just-types
```

![Schema에서 타입까지의 흐름](발표자료-assets/schema-type-flow.svg)

**코드 위치**

- Schema: `openmetadata-spec/src/main/resources/json/schema/`
- 생성 스크립트: `openmetadata-ui/src/main/resources/ui/json2ts.sh`
- 생성 타입: `openmetadata-ui/src/main/resources/ui/src/generated/`

## 3. Theme & 브랜딩

**UI 페이지**

`Settings > Preferences > Theme`

| 설정 | UI 반영 범위 |
|---|---|
| `primaryColor` | 기본 강조색, 버튼, 내비게이션 |
| `hoverColor` | hover 상태 |
| `selectedColor` | 선택 상태 |
| 로고·모노그램·favicon | 브랜드 식별 요소 |

```typescript
const palette = generatePalette(primaryColor);
const hoverColor = savedHoverColor || palette[2];
const selectedColor = savedSelectedColor || palette[8];
```

## 4. Persona 기반 개인화

**UI 페이지**

`Settings > Personas`

- Persona: 역할별 UI 구성을 위한 엔티티
- User: 기본 Persona를 지정할 수 있음
- Selected Persona: 현재 화면이 참조하는 Persona

```typescript
const pageFQN =
  `${EntityType.PERSONA}.${selectedPersona?.fullyQualifiedName}`;
const doc = await getDocumentByFQN(pageFQN);
```

![Persona 선택 흐름](발표자료-assets/persona-flow.svg)

**코드 위치**

- Schema: `openmetadata-spec/.../entity/teams/persona.json`
- UI 조회: `src/hooks/useCustomPages.ts`

## 5. 커스터마이즈 가능한 Landing Page

**설정 UI 페이지**

`Settings > Personas > <Persona> > Customize UI > Landing Page`

**렌더링 UI 페이지**

`Home / My Data`

- Persona별 Landing Page에 위젯을 추가·제거·재배열한다.
- 저장된 레이아웃은 선택 Persona의 페이지 구성으로 읽힌다.
- 대표 위젯: Activity Feed, KPI, Announcements, Tasks, Recently Viewed

```typescript
const customizedPage = doc.data?.pages?.find(
  (page) => page?.pageType === pageType
);
```
